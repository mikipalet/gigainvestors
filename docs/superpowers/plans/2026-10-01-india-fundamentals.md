# India fundamentals implementation plan

User specification: official annual consolidated financial statements for the existing Nifty 50 membership, preserving canonical ADR identities, recording source provenance, unchanged integrity checks, and a per-company report. Work inline; no subagents, builds, analysis, publication, or push. Stop below 5 GiB available on `/`; all downloaded data uses `raw/india`.

1. Record NSE annual filing lists and actual XBRL/legacy HTML for RELIANCE, TCS, HDFCBANK, INFY, ITC. BSE API and MCA probes returned 403. NSE requires `period=Annual`; arbitrary date-only queries returned empty arrays. Reject placeholder `xbrl/-` links.
2. Add fixture tests for annual versus quarterly contexts, already-absolute INR units, parent profit/equity, complete debt/capex components, bank fields, identity mismatch, incomplete legacy statements, and Yahoo overlap conflicts. Run failing tests before implementing `lib/value/india/filings.ts`.
3. Parse structured official filings with explicit source tags and dates. NSE's generated XML sometimes has quarterly context dates for annual facts; accept annual reporting-period facts only when they match the annual filing metadata. Never extrapolate missing years, sum quarters, or turn missing statement lines into zeros.
4. Add a dedicated `scripts/value/india-fundamentals.ts` command. Select only Nifty 50 canonical ids; resolve exchange symbols explicitly. Use bounded downloads, disk checks, one cache, atomic fundamentals writes, and per-company failures. Merge same-currency Yahoo observations only after overlapping annual totals agree; preserve incompatible pre-existing histories instead of splicing currencies or ADR share bases.
5. Run five pilots, then all fifty. Inspect missing years/fields and attempt the available official alternatives. Record obtained and retained years separately because the unchanged integrity checker may trim gaps. If no official keyless source works, use company IR reports and the Jev client with numeric extraction and verbatim evidence.
6. Run focused fixture/regression tests, review diffs, write the requested report with exact access attempts and coverage limitations, and commit `value: India fundamentals from official filings` locally.
