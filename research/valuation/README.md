Sequence:
1. Baseline replay: `node --import tsx research/valuation/replay.ts` (on baseline code); `python3 research/valuation/audit.py`; `freeze-audit.py` produced the one-time phase-1 receipt.
2. `prepare-candidates.py` was run against baseline sources only, after the audit, and created independent source copies. It refuses drift in the phase-1 bindings. The sealed source archive supports reproduction after production changes.
3. `candidate-checks.ts` verifies accounting identity, fallback treatment, eligibility, downturn caps, cyclicality and bridge arithmetic. `PART=0 PARTS=2` and `PART=1 PARTS=2 node --import tsx research/valuation/candidate-replay.ts` process disjoint identities. These are data workers, not agents.
4. `evaluate.py` uses original corrected quarterly-portfolio measurement and applies the fixed gates. Its one-time opening receipt is preserved. For an independent rerun, use a separate checkout/root and preserve the original receipt rather than overwriting it. The script refuses to replace that receipt.
5. `current-candidates.ts` computes same-input current diagnostics, not publishable analyses; it records discrepancies between its baseline and live. `outputs/current-experimental-changes.csv` lists every hypothetical quality/value/price/buy change, and `rejected-experimental-buy-proposals.json` records every hypothetical buy flip with reasons. All are rejected for this release, and none is an approval. One company (457190.KO) lacks persisted inputs.
6. `docs/value/rules-5/harness/` runs the local release checks, with a read-only live-corpus mount and loopback-only network namespace. The REAL publication uses a local bare remote and stub Blob. It is not external publication. The unchanged approved-verdict manifest is empty; production continuity holds unapproved live buy flips.

`outputs/baseline-predictiveness.csv` includes three/five-year quintiles, pass/fail hit rates and denominators. `quarter-correlations.csv` retains every within-quarter Spearman; `correlation-summary.csv` averages quarters equally. `iconic-buy-frequency.csv` shows available—not whole-lifetime—history. `losing-buys.csv` includes every negative matured buy outcome; repeated observations/horizons are dependent. `path-outcomes.csv` is explicitly a listing-venue comparison (see the frozen-audit addendum), not the country-based ship test.

Limitations inherited from research-1: surviving universe, restated financials, current country/classification/bond/FX selection inputs, retrospective judgements, incomplete filing dates and delayed-entry/FX coverage, missing bankruptcies and corporate actions. Currency-mismatched/unavailable records retain the same stored decisions in both portfolio arms. Unavailable outcomes do not become wins. The tests compare this implementation and cannot establish prospective investment performance or precise intrinsic values.
