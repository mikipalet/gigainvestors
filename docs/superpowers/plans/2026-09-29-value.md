# value.gigainvestors.com Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the five quality tests plus a price check for the product named by `VALUE_PRODUCT_NAME` in `lib/value/brand.ts` (numbers in code, report reading by Jev) over every listed company EODHD and EDINET cover, and publish the dossiers and a ranked index on `value.gigainvestors.com`.

**Architecture:** An offline, resumable five-stage pipeline (`scripts/value/` + `lib/value/`) runs on the ZERN box and writes a corpus under `$VALUE_CORPUS_DIR`; its publish stage force-pushes compact JSON to the public repo `mikipalet/gigainvestors-value-data`. The existing Next 16 app serves `app/value/**` (host-rewritten from the subdomain by `proxy.ts`) and reads that JSON from `raw.githubusercontent.com` with ISR (revalidate daily).

**Tech Stack:** TypeScript (tsx scripts), Next 16.3 App Router, vitest, Playwright, zod. HTTP: EODHD, SEC EDGAR, filings.xbrl.org, EDINET API v2, Stooq, TypeSafe Jev (`POST https://api.typesafe.ai/v1/systemone`). No new runtime dependencies unless a task says so.

**Spec:** `docs/superpowers/specs/2026-09-29-value-design.md` (read it before any task).

## Global Constraints

- Every number, date and ratio is computed in code. Jev only reads prose and answers `noul` / `choice` / `score` questions. Never ask Jev to compare numbers or dates.
- No blended score. Six tests, each `pass | fail | unclear | na`.
- Thresholds live ONLY in `lib/value/config.ts`.
- Secrets from env: `EODHD_API_KEY`, `JEV_API_KEY`, `EDINET_API_KEY`, `SEC_USER_AGENT` (default `"GigaInvestors value hello@gigainvestors.com"`). Never log them.
- Corpus root: `process.env.VALUE_CORPUS_DIR ?? path.join(os.homedir(), "value-corpus")`. Never `/tmp`.
- Tests never touch the network: recorded fixtures under `tests/fixtures/value/`.
- Existing gigainvestors pages must not change behaviour. Design system: tokens in `app/globals.css` (paper `#f4f2ec`, ink `#111`, `--buy`, `--sell`, Inter tabular). Paper only, no dark mode. Pass = buy green, fail = sell red, unclear = ink at 40%, na = ink at 20%.
- No em dashes in any user-facing copy.
- Rate limits: EODHD 100k calls/day (fundamentals = 10 calls each, measured), SEC 10 req/s, Jev 1,200 req/min and 250k tokens/s, EDINET be polite (≤ 3 req/s).
- Functions with more than two parameters take one object parameter.

## Review Focus

1. Company with fewer than 7 years, restated currency, or broken balance sheet: must be `insufficient_data`, greyed in the index, never ranked. Test in Task 3.
2. Negative or zero normalised owner earnings / equity: valuation must be `null` with reason, not a negative intrinsic value or a division blow-up; price test `unclear`. Test in Task 5.
3. Banks and insurers: ROIC, gross margin and accruals do not apply; they must go through the financials path (ROE, book value) and never fail the moat test because `grossProfit` is null. Test in Task 4.
4. Jev chunk aggregation when a section is missing entirely: the question is `unclear` (no answer), not a `0` probability read as "no". Test in Task 9.
5. Dossier page for an id that does not exist or whose shard is missing: 404, not a 500, and no crash when `prices/{country}.json` lacks the id (shows "no price"). Test in Task 12.

## Shared contract (written by Task 1, used by all)

`lib/value/types.ts`:

```ts
export type Id = string; // EODHD style "KO.US", "ASML.AS", "0700.HK"; Japan "8058.JP"
export type Kind = "operating" | "bank" | "insurer";
export type Result = "pass" | "fail" | "unclear" | "na";
export type TestKey = "understandable" | "moat" | "economics" | "management" | "accounting" | "price";
export const QUALITY_TESTS: TestKey[] = ["understandable", "moat", "economics", "management", "accounting"];

export interface Company {
  id: Id;
  name: string;
  code: string;
  exchange: string;
  country: string; // ISO2
  currency: string; // trading currency
  isin: string | null;
  cik: string | null;
  lei: string | null;
  edinetCode: string | null;
  sector: string | null;
  industry: string | null;
  kind: Kind;
  listings: Id[];
  marketCapUsd: number | null;
  description: string | null;
  source: "eodhd" | "edinet";
}

// One fiscal year, reporting currency, absolute units. null = not reported.
// Sign convention: capex, buybacks, dividendsPaid, acquisitions are POSITIVE amounts spent.
export interface Year {
  fy: number;
  end: string; // ISO date
  revenue: number | null;
  grossProfit: number | null;
  operatingIncome: number | null;
  preTaxIncome: number | null;
  taxExpense: number | null;
  netIncome: number | null;
  interestExpense: number | null;
  da: number | null;
  sbc: number | null;
  nonRecurring: number | null;
  ocf: number | null;
  capex: number | null;
  dividendsPaid: number | null;
  buybacks: number | null;
  issuance: number | null;
  acquisitions: number | null;
  receivables: number | null;
  inventory: number | null;
  payables: number | null;
  cash: number | null;
  totalDebt: number | null;
  equity: number | null;
  goodwill: number | null;
  intangibles: number | null;
  ppe: number | null;
  totalAssets: number | null;
  totalLiabilities: number | null;
  currentAssets: number | null;
  currentLiabilities: number | null;
  dilutedShares: number | null;
  marketCap: number | null; // year-end, reporting currency, when derivable
}

export interface Fundamentals {
  id: Id;
  currency: string; // reporting currency
  years: Year[]; // ascending fy, one per fy
  integrity: { ok: boolean; reasons: string[] };
  fetchedAt: string;
}

export type Series = Array<[number, number | null]>; // [fy, value]

export interface JevAnswer {
  q: string; // question id
  label: string; // plain statement shown in UI, e.g. "Describes switching costs"
  kind: "noul" | "choice" | "score";
  value: number | string | null; // noul prob, choice key, score value; null = section missing
  probability: number | null; // noul prob, or prob of chosen option, or confidence for score
  section: SectionKey | "description";
  evidence: string | null; // best paragraph, filled by the evidence pass
  trusted: boolean; // passed the accuracy check (lib/value/jev-trust.json)
}

export interface TestOutcome {
  key: TestKey;
  result: Result;
  numeric: Result;
  reasons: string[]; // short plain sentences, e.g. "ROIC median 31% over 10 years"
  metrics: Record<string, number | null>;
  series: Record<string, Series>;
  jev: JevAnswer[];
}

export interface Valuation {
  method: "owner_earnings" | "book_value";
  currency: string;
  normalized: number; // owner earnings (or book value per share for book_value)
  growth: number;
  discountRate: number;
  terminalGrowth: number;
  bondYield: number | null;
  netCash: number;
  shares: number;
  perShare: { low: number; mid: number; high: number };
  equityBondYield: number | null;
  bridge: Array<{ label: string; value: number }>;
  assumptions: string[];
}

export type SectionKey =
  | "business" | "risk" | "mdna" | "letter" | "capital" | "compensation" | "notes" | "auditor";

export interface ReportMeta {
  id: Id;
  kind: "10-K" | "20-F" | "40-F" | "ESEF" | "EDINET" | "description";
  url: string | null;
  filed: string | null;
  period: string | null;
  sections: SectionKey[];
}

export interface Analysis {
  id: Id;
  company: Company;
  asOf: string;
  status: "scored" | "insufficient_data";
  report: ReportMeta;
  tests: Record<Exclude<TestKey, "price">, TestOutcome>;
  valuation: Valuation | null;
  valuationReason: string | null; // why valuation is null
  versions: { pipeline: string; questions: string };
}

export interface Dossier extends Analysis {
  holders: Array<{ code: string; name: string }>; // superinvestors, from data/store
  series: Record<string, Series>; // revenue, ownerEarnings, roic, grossMargin, shares, bvps
}

// Compact index row. t = one char per quality test in QUALITY_TESTS order: P F U N.
export interface IndexRow {
  id: Id;
  n: string;
  c: string;
  s: string | null;
  k: Kind;
  mc: number | null;
  v: [number, number, number] | null; // per-share low, mid, high in `cur`
  cur: string;
  t: string;
  g: string[]; // Jev tag ids, trusted questions only
  h: number; // superinvestor holders
  st: "s" | "i"; // scored / insufficient
}

export type PriceMap = Record<Id, [number, string]>; // close, ISO date, in trading currency
```

Data repo layout (`mikipalet/gigainvestors-value-data`, branch `main`):

```
meta.json                 { asOf, counts: { universe, scored, insufficient }, versions, tags: Record<tagId,label> }
index/default.json        IndexRow[]  (pass all 5 quality tests OR fail exactly one), sorted by mc desc
index/{country}.json      IndexRow[]  every company of that country
dossiers/{shard}.json     Record<Id, Dossier>   shard = fnv1a32(id) % 600, zero-padded to 3
prices/{country}.json     PriceMap
top.json                  Id[]  top 2000 by marketCapUsd (for generateStaticParams)
```

Price result is computed at render AND at publish with one function, `priceTest(valuation, price)` in `lib/value/price-test.ts`.

### Task 5: Valuation and price test

**Files:**
- Create: `lib/value/valuation.ts`, `lib/value/price-test.ts`
- Test: `tests/unit/value/valuation.test.ts`

**Interfaces:**
- Consumes: `Year`, `T`, `Kind`, `metrics.ts`.
- Produces:
  - `ownerEarningsSeries(years: Year[]): Series` — OE_t = netIncome + da − maintenanceCapex − sbc; maintenanceCapex = max(0, capex − growthCapex), growthCapex = max(0, (avgPpe/revenue over the last 5 years) × (revenue_t − revenue_{t−1})); sbc null → 0 with an assumption line "stock compensation not reported".
  - `presentValue({ oe, g, r, terminal }: { oe: number; g: number; r: number; terminal: number }): number` — years 1..10, growth g for t ≤ 5, then linear fade `g + (terminal − g) × (t − 5)/5`, terminal value `OE_10 × (1 + terminal)/(r − terminal)` discounted at year 10.
  - `valueCompany({ years, kind, bondYield, cyclical }: {...}): { valuation: Valuation | null; reason: string | null }` — operating: normalised = median OE last 5 (7 if cyclical); growth = clamp(min(OE/share 10y CAGR, revenue/share 10y CAGR, roiic × reinvestmentRate), 0, T.valuation.maxGrowth) ignoring null terms (all null → 0); r = max(T.valuation.minDiscount, (bondYield ?? 0.04) + T.valuation.bondSpread); low = PV(g/2, r+0.01), mid = PV(g, r), high = PV(g, r−0.01); add netCash (cash − totalDebt, latest year); divide by dilutedShares. normalised ≤ 0 → `{ valuation: null, reason: "owner earnings not positive" }`; shares null → reason "no share count".
